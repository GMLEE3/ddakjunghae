# 딱정해 MVP 정의
> Minimum Viable Product - 최소 기능 제품

---

## 🎯 MVP 목표

**"모임 장소 결정 고민 해결"** - 복수 인원의 중간 지점에서 맛집 추천

---

## ✅ MVP 포함 기능

| 기능 | 설명 | 상태 |
|------|------|------|
| 역/정류장 자동완성 | 지하철역, 버스정류장 검색 | ✅ 완료 |
| 주소 입력 | 단일/복수 위치 입력 | ✅ 완료 |
| 중간 지점 계산 | 복수 주소의 공평한 중간 위치 | ✅ 완료 |
| 모임 성격 선택 | 회사/친구/연인 테마 | ✅ 완료 |
| **반경 기반 맛집 검색** | 800m/1.5km/2km 반경 검색 (Kakao) | ✅ 완료 |
| **도보 거리 표시** | 각 맛집 도보 시간(분) + 거리(m) | ✅ 완료 |
| AI 맛집 추천 | 정석/핫플/실속 3가지 타입 | ✅ 완료 |
| 맛집 상세 팝업 | 클릭 시 상세 정보 + 지도 링크 | ✅ 완료 |
| 공유 기능 | 링크 복사 + Web Share API | ✅ 완료 |
| 가게 이미지 | 네이버 이미지 검색 + 카테고리 폴백 | ✅ 완료 |
